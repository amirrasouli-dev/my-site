وبلاگ من

نکته‌هایی که تو پروژه‌های واقعی یاد می‌گیرم رو اینجا می‌نویسم. مقاله‌ها یکی‌یکی منتشر می‌شن.

CSS

Flexbox یا Grid؟ کدوم رو کِی بزنیم

Flexbox برای چیدمان یک‌بعدی (یه ردیف یا یه ستون) مثل منو و دکمه‌هاست و Grid برای چیدمان دوبعدی صفحه. تو این مقاله با مثال می‌بینیم کجا کدوم بهتره و چطور ترکیبشون کنیم.

ریسپانسیو

ریسپانسیو کردن سایت بدون دردسر

از تگ viewport و واحدهای نسبی شروع می‌کنیم، بعد روش موبایل‌اول و media queryها. در آخر هم اشتباه‌هایی که باعث می‌شن سایت تو گوشی بهم بریزه.

فارسی و RTL

۵ اشتباه رایج در طراحی راست‌به‌چپ

یادت رفتن dir و lang، استفاده از left و right به‌جای ویژگی‌های منطقی، آیکون‌هایی که باید برعکس بشن، قاطی شدن اعداد و متن انگلیسی، و فونت‌هایی که ارقام فارسی ندارن.

سرعت

WebP و سرعت سایت

چرا WebP معمولاً از JPEG و PNG سبک‌تره، چطور تصویرها رو تبدیل کنیم و با lazy loading و ویژگی‌های width و height جلوی پرش صفحه رو بگیریم.

سئو

سئوی فنی برای سایت‌های تازه‌کار

چک‌لیست ساده: عنوان و توضیح یکتا برای هر صفحه، یک h1، ساختار درست هدینگ‌ها، فایل sitemap و robots، تگ canonical و سرعت لود.

جاوااسکریپت

جاوااسکریپت ساده یا فریم‌ورک؟

برای سایت‌های ایستا و کوچیک، Vanilla JS معمولاً کافیه. اما وقتی تعامل و وضعیت (state) پیچیده می‌شه، سراغ فریم‌ورکی مثل React می‌ریم. اینجا مرز تصمیم رو می‌گم.
